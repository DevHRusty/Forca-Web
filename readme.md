# 🎮 Jogo da Forca Web

Um jogo da forca desenvolvido com HTML, CSS e JavaScript puro.

## 🎯 Como jogar

1. Abra o arquivo `index.html` no navegador
2. Uma palavra aleatória será sorteada
3. Digite uma letra por vez e pressione Enter ou clique em ???
4. Você tem 7 tentativas antes de perder
5. Adivinhe a palavra antes do boneco ser completado!

## ✅ Funcionalidades

- Palavras aleatórias sorteadas a cada partida
- Forca desenhada em Canvas que evolui com os erros
- Letras erradas destacadas em vermelho
- Suporte a Enter para confirmar letra
- Botão de jogar novamente

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- Canvas API
